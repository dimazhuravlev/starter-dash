# Деплой: как включить карту

На опубликованном сайте карта работает только если подставлен Mapbox-токен.

## Один раз перед деплоем

1. Возьмите токен с [account.mapbox.com](https://account.mapbox.com/access-tokens/) (публичный, начинается с `pk.`).
2. В корне проекта создайте файл `.env` и добавьте строку:
   ```
   VITE_MAPBOX_ACCESS_TOKEN=pk.ваш_токен
   ```
3. Выполните:
   ```bash
   npm run set-mapbox-token
   ```
   Скрипт подставит токен из `.env` в `index.html`.
4. Соберите и задеплойте как обычно:
   ```bash
   npm run build
   ```
   Дальше загружаете содержимое папки `dist` на хостинг.

При следующем деплое снова запускайте `npm run set-mapbox-token` перед `npm run build`.

---

**Если деплой идёт через Vercel / Netlify и т.п.:** в настройках проекта добавьте переменную окружения `VITE_MAPBOX_ACCESS_TOKEN` (значение — ваш токен). В команду сборки укажите:
```bash
npm run set-mapbox-token && npm run build
```
Тогда токен подставится при каждой сборке из переменной окружения, в репозитории его хранить не нужно.
